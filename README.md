# Predicting Student Grades with Linear Regression  

![Cover Image](https://github.com/Brianhulela/linear_regression_student_perfomance/blob/master/actual_vs_predicted.png) 

This repository contains the code and data for a project aimed at predicting student grades based on factors such as socioeconomic status, study habits, sleep patterns, and attendance. The model uses multivariate linear regression to analyze the relationships and predict outcomes. 

For a detailed explanation of this project, visit the Medium article here: [Medium Article](https://medium.com/@brianhulela/predicting-student-grades-with-linear-regression-5f0acc14190d)

## Features  
- Data preprocessing and visualization  
- Implementation of linear regression using `scikit-learn`  
- Evaluation of model performance using metrics like MAE, MSE, and R²  
- Visualizations to assess predictions and errors
